# hw_arm 算法工具箱

> 6 轴机械臂的**离线算法与辨识工具**，与 `hw_arm_ws`（ROS 运行时）分离。
> 目标：在不依赖真机的情况下，把重力补偿、参数辨识、前馈补偿的数学先跑通。

## 目录约定

沿用 `robotics-tutorial.dmbot.cn` 第 05 章的规范：

| 约定 | 含义 | 示例 |
|---|---|---|
| **数字前缀 10/20/30** | 模块顺序 | `10_模型/` → `20_重力补偿/` |
| **字母前缀** | 系列归属 | `m10_` = 模型模块的代码 |
| **每个模块一个 `_总大纲.md`** | 路线图 + 依赖 + 索引 | `00_总大纲/算法工具箱_总大纲.md` |

## 与 ROS 运行时的关系

```
~/hw_arm/algo/            离线：算模型、做辨识、生成轨迹、验证数学
        │
        │  参数（JSON/YAML）：
        │    · 重力参数 θ_g（辨识结果）
        │    · 摩擦系数 fc/fv
        │    · 前馈曲线 τ_ff(t)
        ▼
~/hw_arm/hw_arm_ws/       在线：250 Hz 实时控制，tau_ff 填入 MIT 帧
```

**算法在这里开发和验证，运行时只消费它的产物。**

## 快速开始

```bash
cd ~/hw_arm/algo
source /opt/ros/jazzy/setup.bash          # 提供 pinocchio
python3 scripts/check_model.py            # 模型自检
```
