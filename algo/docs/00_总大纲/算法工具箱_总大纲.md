> 版本 v0.1（2026-11-07）
> 目标：在机械组图纸完成前，把重力补偿与参数辨识的**数学与代码**先跑通

## 一、为什么独立于 ROS 工作空间

```
hw_arm_ws      实时运行时（250 Hz、CAN、ros2_control）
algo           离线算法（模型、辨识、验证、轨迹生成）
```

**理由**：辨识和验证是"算一次、用很久"，不该混进实时回路；而且它们不依赖电机在线。

## 四、关键技术决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 动力学库 | **Pinocchio** | 课程推荐，Crocoddyl/代码生成同源 |
| 重力补偿位置 | **插件内 tau_ff** | 位置控制和前馈同时生效（优于 Mockway 的二选一） |
| 参数辨识顺序 | **先静态重力，后完整 SysId** | 重力占误差 96%，且静态辨识不需要激励轨迹 |
| 加速度来源 | **轨迹解析导数** | 数值差分噪声是信号的 24 倍 |
| 摩擦模型 | `fc·tanh(dq/0.01) + fv·dq` | 避免零速抖动 |
| 在线积分 | 需要 | 纯 P 的死区 = fc/kp 无法避免 |
