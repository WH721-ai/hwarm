# C-05 重力辨识：精度分析与零位核查

> 2026-11-26 · 40 个样本（20 位形 × 双向）/ 真机数据

## 1. 零位一致性核查：**模型与真机一致，不需要改**

用户的观察："真机零位时 link2 和 link3 完全平行于地面"。

用 FK 算 q=0 时各连杆 body 的 z 轴在世界系的方向：

| 连杆 | z 轴方向 | 判定 |
|---|---|---|
| joint1 | [0, 0, 1] | 竖直 |
| **joint2** | [−0.475, 0.88, 0] | **水平** |
| **joint3** | [0.475, −0.88, 0] | **水平** |
| joint4 | [0.877, 0.473, −0.082] | 水平 |
| joint5 | [0.478, −0.877, 0.046] | 水平 |
| joint6 | [0.873, 0.48, 0.087] | 水平 |

**→ RViz 在 q=0 时也是 link2/link3 水平，与真机观察完全一致。**

手臂在 q=0 是"Z 形折叠"姿态：所有连杆都水平，但各关节原点的 z
从 0.055 递增到 0.244，所以 TCP 仍在基座上方 24 cm —— 看起来"折叠着立起来"。

### 数据反向验证

给 joint2/joint3 加零位偏置，扫描 ±172° / ±86°，重做"重力+偏置"最小二乘：

| 零位偏置 | rms |
|---|---|
| 0（当前 URDF） | **0.562** |
| Δq2 = −28.6°, Δq3 = −28.6°（最优） | 0.522 |
| 其它所有组合 | 0.55 ~ 1.51 |

**曲面上没有任何尖锐极小值，更没有 90° 量级的台阶。**
⇒ 数据不支持"零位差了 90°"，当前 URDF 的关节零位是对的。

## 3. 残差的三个来源（按重要性）

### ① joint3 的静摩擦死区 ±1.2 N·m —— **最大**

**证据**：40 个样本里有 15 对"位形差 < 2°"的样本，力矩差最大 **2.34 N·m**，
而重力模型本该只差 0.03~0.2 N·m。中位数上"多出来" **1.20 N·m**，几乎全在 joint3。

**典型原始数据**：

| q3 | R3 | tag |
|---|---|---|
| 82.9° | +1.152 | A |
| 83.7° | +2.157 | A |
| 83.7° | +2.103 | B |
| 84.2° | −0.347 | B |

1.3° 内跳了 2.5 N·m，而 dτ3/dq3 ≈ 0.09 N·m/° 只该跳 0.12。

**机理**：kp=70 的位置环下，机械臂停在"静摩擦刚好平衡"的位置，
停在哪**取决于卡在死区哪一侧**，与重力无关。任何参数辨识都消不掉。

### ② joint1 的 0.658 N·m —— **硬地板**

joint1 是竖直偏航轴，**重力力矩恒为 0**（500 个随机位形实测 ±5e-7 N·m）。
所以**任何 θ 都改不了 joint1 的预测值** —— 测到的 0.658 全是非重力项：
线束拉扯 / 扭矩零点 / 基座不绝对水平。

**这一项单独就把整体 rms 的地板压在 0.658/√6 = 0.269。**

### ③ 参数辨识误差 —— 已经压到很小

joint2 从 1.323 → 0.310，说明辨识本身工作正常。

## 4. 抖动 + 摩擦列能提升多少

### 抖动（`--dither 3`）：**预计 0.475 → ~0.34（约 1.4×）**

基于当前每轴残差做的投影（假设死区被平均掉、joint3 只剩模型误差）：

| joint3 残差 | 整体 rms |
|---|---|
| 0.40（死区只消一半） | 0.359 |
| **0.25（中性预期）** | **0.336** |
| 0.15（乐观） | 0.326 |

### 库仑摩擦列（A/B 符号）：**单独没用**

A/B 两组的位形**没对齐**（j3 差 2.32°、j5 差 2.05°），
摩擦项会被重力项吸收 —— 实测辨识出的摩擦只有 −0.23~+0.09 N·m，
远小于真实死区 1.2 N·m。**必须靠抖动，光靠双向接近不够。**

### 突破 0.3 的前提：搞清楚 joint1 那 0.66

| joint1 残差 | joint3=0.25 时的整体 rms |
|---|---|
| 0.66（不动） | 0.336 |
| 0.35（降一半） | **0.247** |
| 0.15（基本消除） | 0.210 |

**joint1 的 0.66 不是辨识能解决的，需要找机理**（线束？基座水平度？扭矩零点漂移？）。

## 5. 结论

| 问题 | 回答 |
|---|---|
| 零位对不对 | ✅ **对**，模型与真机一致，数据也不支持零位偏差 |
| 这版模型比标称好多少 | ✅ **1.86×**（0.884 → 0.475） |
| 抖动值不值得做 | ✅ **值得**，预期 1.4×（0.475 → 0.34） |
| 摩擦列有用吗 | ⚠️ **单独没用**，A/B 位形没对齐；要靠抖动 |
| 能到 0.2 吗 | ❌ **不能**，joint1 的 0.66 把地板压在 0.269 |
| 对位置控制够用吗 | ✅ 0.475 N·m ÷ kp70 = **0.0068 rad = 0.39°** 静态误差 |
