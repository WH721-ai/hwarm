# 用动力学做电机选型：现成工具调研 + 自研脚本

> 问题：有没有开源项目能"吃 URDF、吐每个关节的力矩、直接用于选电机"？
> 答案：**有 2 个研究型工具很接近，但没有一个是"通用、可跑、几行命令出表"的**。
> 结论：**自己写一个不掉价——我们已经有 Pinocchio，250 行、0.5 秒跑完。脚本已经写好了。**

---

## 1. 调研结果

| 项目 | 是什么 | 能不能直接用 | 差距 |
|---|---|---|---|
| [**Robodimm**](https://github.com/ual-arm/robodimm)（MIT，TypeScript，3★） | 浏览器里的机器人设计环境：参数化编辑 → 轨迹录制 → **确定性执行器选型**（`TorqueLog` + 电机目录 → 唯一 `best` 候选），后端可选 Pinocchio 4 跑高保真逆动力学 | ❌ | 只支持 **CR6/CR4 两个机型**（硬编码），不是通用 URDF 工具；偏"设计演示" |
| [**Sim4RAD**](https://export.arxiv.org/abs/2610.17534)（MATLAB 工具包） | 设计阶段的**尺寸-执行器选型 + URDF 模型验证**，方法学最接近 | ⚠️ | 要 MATLAB 许可证；不面向我们这种"已有 URDF，只想算力矩"的场景 |
| [`inverse_dynamics_solver`](https://index.ros.org/r/inverse_dynamics_solver/)（ROS 包） | 统一的逆动力学**接口**（KDL/RBDL/Pinocchio 后端可换） | ⚠️ | 只是接口，**不做选型**：不给最坏位形、不给 RMS、不给电机侧折算 |
| [URDF→Dynamics Pipeline](https://github.com/avyuktchitta-droid/URDF-to-Modern-Robotics-Dynamics-Pipeline) | 从 URDF 抽螺旋轴/空间惯量、做逆动力学验证 | ⚠️ | 教学性质，不做选型 |
| Pinocchio / RBDL / KDL / Drake | 动力学库 | ⚠️ | 给 `τ = rnea(q,v,a)`，**选型方法学要自己写** |
| MATLAB Simscape / Maxon/Kollmorgen 在线选型器 | 商业方案 | ❌ | 贵/闭源/绑供应商 |

**共同的缺口**：没有人把"**最坏位形搜索 + 峰值/RMS 双指标 + 减速比与效率折算 + 与电机目录匹配**"打包成一个对任意 URDF 都能跑的脚本。

## 3. 方法学（这是选型真正值钱的部分）

### 3.1 三档力矩，用途完全不同

| 指标 | 怎么算 | 选什么 |
|---|---|---|
| **保持力矩**（gravity） | `rnea(q, 0, 0)` 在最坏位形取最大 | 静止保持、抱闸、驱动器额定 |
| **峰值力矩**（peak） | `rnea(q, v_max, a_max)` 取最大 | 电机峰值能力、减速器峰值 |
| **RMS 力矩**（thermal） | 一个正弦工作循环上的 `√(∫τ²dt/T)` | **电机热校核**（决定会不会烧） |

**只算峰值是最常见的错误**：电机能不能扛住峰值只决定"会不会失步/过流"，能不能长期工作是 RMS 决定的。

### 3.2 折算到电机侧

```
τ_motor = τ_joint × 安全系数 / (减速比 × 效率)
n_motor = v_max × 减速比
```

谐波减速器效率取 **0.7–0.8**，行星 0.85–0.95。安全系数：静态 1.5、动态 1.5–2.0、有冲击 2.5。

### 3.3 最坏位形怎么找

- 关节打到上下限的组合（`2n` 个顶点）+ 2 万次随机采样
- 每个关节单独记录 `max |τ_j|` 与对应 `q`
- 采样而非解析优化：0.5 s 出结果，工程上够用（要更严格可以上 CMA-ES，但收益小）

## 4. 在你这个 6 轴臂上的实测（过渡 URDF，载荷 1 kg）

```
工况：vmax=1.0 rad/s  amax=5.0 rad/s²  循环 0.5 Hz  减速比 100  效率 0.8  安全系数 1.5
```

| 关节 | 保持 | 峰值 | RMS | 峰值×1.5 | URDF 写的 effort | 判定 |
|---|---|---|---|---|---|---|
| link_002 | -6.46 | 7.56 | 3.19 | **11.34** | 10.00 | ⚠️ **不足** |
| link_003 | -5.96 | 7.37 | 3.08 | **11.06** | 10.00 | ⚠️ **不足** |
| link_004 | 3.07 | 3.83 | 1.31 | 5.74 | 10.00 | OK |
| link_005 | -1.09 | 1.26 | 0.24 | 1.90 | 10.00 | OK |
| link_006 | -1.10 | 1.41 | 0.37 | 2.12 | 10.00 | OK |
| link_007 | 0.49 | 0.66 | 0.20 | 0.98 | 10.00 | OK |

**结论（针对这份过渡 URDF）**：
- **前两个关节是瓶颈**：1 kg 载荷 + 1.5 安全系数下需要 **11.1–11.3 N·m**，而 URDF 里写的是 10 N·m → 要么选更大电机，要么把安全系数降到 1.2、要么减重/缩短力臂。
- 后四个关节余量很大（< 6 N·m），可以用小一号的电机 —— **这正是选型脚本的价值：避免整臂都用大电机**。

> 注意这是**过渡 URDF**（质量 1.85 kg，而且惯量是建模值）。实机 URDF 到位后重跑一次，数字会变。

## 5. 这个脚本的边界（别当作真值）

| 没建模的东西 | 影响 | 怎么办 |
|---|---|---|
| **摩擦、背隙、减速器刚度** | 实际输出力矩要更大（尤其低速关节） | 安全系数里含一部分；重要的话做系统辨识 |
| **载荷质心** | 影响巨大：同样 1 kg，质心偏 5 cm 能让末轴从 **0 → 1.15 N·m** | 必须给 `--payload-offset` |
| **URDF 惯量可信度** | 建模值 ≠ 实测，差 20–50% 很常见 | 称重 + 摆锤/系统辨识 |
| **安装姿态 / 重力方向** | 侧装、倒装会改变最坏位形 | 改 URDF 的 base 变换 |
| **峰值持续时间** | 电机能不能"超一会儿" | 用 RMS + 电机热时间常数校核 |
| **多轴同时加速** | 我的采样已经是同时随机，偏保守 | — |

## 6. 下一步（如果要做成完整工具）

1. **接电机目录**：`--catalog motors.json`，按 (峰值 ≥ 需求, 转速 ≥ 需求, RMS ≤ 额定) 自动筛，输出候选清单
2. **加转速校核**：目前只打印需求，没和电机最高转速比
3. **加装 3D 可视化**：标出最坏位形长什么样（一眼看出是不是"伸直 + 全负载"）
4. **接实机辨识**：用测到的电流 × 转矩常数回算真实 τ，校准 URDF 惯量
5. **打包开源**：这东西本身就是 `docs/OPEN-SOURCE.md` 里提到的一个候选（比 Robodimm 更通用，比 Sim4RAD 更轻）
